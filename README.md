# Memory Game

Игра на память: найдите все пары карточек за минимальное число ходов.

## О приложении

Классический «мемори» с карточками-фруктами. Игрок открывает по две карточки за ход:
если изображения совпали — пара остаётся открытой, иначе карточки переворачиваются обратно.

Возможности:
- Случайная раскладка карточек при каждом запуске
- Счётчик ходов и найденных пар
- Таблица лидеров (топ-10) с сохранением в localStorage
- Адаптивная вёрстка
- Определение победы и финальный результат

Стек: Vanilla JS (ES-модули) + SCSS + Vite.

## Локальный запуск

### Требования
- Node.js 22+
- npm

### Установка

```bash
git clone git@github.com:vadim-mg/memory-game.git
cd memory-game
npm install

```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется на http://localhost:5173 (порт может отличаться — смотрите вывод в консоли).

### Сборка production-версии

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`.

### Предпросмотр собранной версии

```bash
npm run preview
```

## Управление

- Клик по карточке — открыть её
- Секретный код (iddqd) — читерская победа со случайным числом ходов (для тестирования таблицы)
